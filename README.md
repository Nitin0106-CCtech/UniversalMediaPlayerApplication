# UniversalMediaPlayerApplication
Universal Media Player is a C# console application that demonstrates the Adapter Design Pattern. It enables playback of multiple media formats such as MP3, MP4, and VLC through a single interface. Adapters bridge incompatible media player interfaces, ensuring flexibility, scalability, and maintainability.
